1. Project Overview

An Opera/Chrome browser extension (Manifest V3) for capturing, organizing, and reviewing Google Translate translations. All data is stored locally in IndexedDB — no accounts, no servers.

Tech Stack
TypeScript ~6.0 (strict) · React 19 · Vite 8 · idb v8 (IndexedDB) · Shadow DOM
Architecture
MV3 service worker · Message-passing bus (40+ types) · Repository pattern · Provider abstraction
Key Constraint
Local-first forever. No cloud sync. All data in IndexedDB / chrome.storage.local.
Build
npm run build (two-pass Vite) · npm run typecheck must return 0 errors

Permission Strategy

  • <all_urls> declared as optional_permissions + optional_host_permissions in manifest (already done)
  • scripting added to required permissions (already done)

Hard Rules (never break)

  • npm run typecheck must return 0 errors after every session
  • No constructor parameter properties — TypeScript flag erasableSyntaxOnly forbids them
  • boolean cannot be an IndexedDB index — use 0/1
  • 'auto' language code stored as null in DB, never as string 'auto'
  • Never call translation APIs from UI code — always through background message bus
  • Local-first forever — no cloud sync
